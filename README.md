# Atlas dos Defeitos de Soldagem — Página de vendas

Landing page responsiva em HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — conteúdo e estrutura da página.
- `assets/css/styles.css` — identidade visual, layout e responsividade.
- `assets/js/main.js` — menu mobile, ano automático e configuração do checkout.

## Visualizar localmente

Abra `index.html` no navegador ou use a extensão Live Server no VS Code.

## Antes de publicar

1. Configure o endereço real do checkout em `CHECKOUT_URL`, no arquivo `assets/js/main.js`.
2. Revise as condições comerciais, preço, forma de entrega e garantia de acordo com a oferta real.
3. Substitua as prévias conceituais por imagens reais das fichas do Atlas, quando estiverem prontas.
4. Inclua depoimentos somente quando houver avaliações reais e autorização de uso.
5. Confira os textos técnicos com referências e profissionais qualificados antes de anunciar o material.

## Publicação

Pode ser publicado pelo GitHub Pages: nas configurações do repositório, acesse **Pages**, selecione a branch principal e a pasta raiz (`/root`).
